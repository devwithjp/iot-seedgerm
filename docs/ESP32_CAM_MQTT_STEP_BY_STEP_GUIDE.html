ESP32-CAM MQTT Setup Guide

For the Mini Germination Chamber: two ESP32-CAM boards publish camera status to Mosquitto over MQTT, while the Raspberry Pi pulls images from each board over HTTP.

What You Are Building First

The pitch PDF uses a Raspberry Pi as the hub for Mosquitto, Home Assistant, logging, and image processing. The clean first milestone is to make both ESP32-CAM boards visible on Wi-Fi and MQTT.

ESP32-CAM 1 Node name: germcam-1
Publishes: status, availability, image URLs
ESP32-CAM 2 Node name: germcam-2
Same firmware, different node name
Raspberry Pi Runs Mosquitto. Later it captures images from /jpg, stores them, and runs germination detection.

Why not send photos through MQTT? JPEG payloads can be large. For the first version, MQTT carries status and URLs; HTTP carries image frames.

Hardware Checklist

  • 1 ESP32-CAM module, usually labelled AI Thinker ESP32-CAM.
  • 1 USB-to-serial adapter, also called FTDI adapter.
  • Jumper wires.
  • Stable 5V power. Do not use 3.3V to power the ESP32-CAM camera board.
  • Computer with Arduino IDE.
  • Raspberry Pi running Mosquitto, or ready to run Mosquitto soon.
Important power note ESP32-CAM boards often fail or reboot if powered weakly. Use the adapter's 5V pin to the ESP32-CAM 5V pin, with common GND.

Step 5 - Upload Firmware

  1. Make sure GPIO0 is connected to GND.
  2. Press RST on the ESP32-CAM.
  3. Click the Arduino IDE upload button.
  4. Wait for Hard resetting via RTS pin... or upload complete.
  5. Disconnect the GPIO0 to GND wire.
  6. Press RST again so the board boots normally.
If upload fails with "Failed to connect" Check GPIO0 is connected to GND, press RST, then upload again. Also check TX/RX are crossed: adapter TX goes to ESP32-CAM U0R, adapter RX goes to ESP32-CAM U0T.

Step 6 - Read The Serial Monitor

  1. Open Tools > Serial Monitor.
  2. Set baud rate to 115200.
  3. Press RST on the ESP32-CAM.
  4. Look for a line like this:
germcam-1 ready: http://192.168.1.42/

Step 8 - Test MQTT On The Raspberry Pi

On the Raspberry Pi, install and start Mosquitto if it is not already running:

sudo apt update
sudo apt install mosquitto mosquitto-clients
sudo systemctl enable --now mosquitto

Subscribe to all germination chamber topics:

mosquitto_sub -h localhost -t 'germination/#' -v

Expected output:

germination/germcam-1/availability online
germination/germcam-1/status {"node":"germcam-1","ip":"192.168.1.42","rssi":-55,"uptime_ms":30122,"free_heap":123456,"jpg_url":"http://192.168.1.42/jpg","stream_url":"http://192.168.1.42/stream"}
germination/germcam-1/jpg_url http://192.168.1.42/jpg
germination/germcam-1/stream_url http://192.168.1.42/stream
If MQTT does not connect Make sure MQTT_HOST in the sketch is the Pi IP address, not the ESP32 IP address. Make sure the Pi and ESP32-CAM are on the same Wi-Fi network.

Step 9 - Flash The Second ESP32-CAM

  1. In the same sketch, change NODE_NAME to germcam-2.
  2. Wire the second board exactly the same way.
  3. Connect GPIO0 to GND.
  4. Press RST.
  5. Upload.
  6. Remove the GPIO0 jumper.
  7. Press RST.
  8. Check browser and MQTT topics for germcam-2.

Step 10 - First Chamber Mounting

  • Mount the cameras before collecting training photos. Moving the camera later changes the dataset.
  • Keep the camera electronics away from condensation and direct mist.
  • Use stable lighting. The LED strip should be consistent between captures.
  • Do not use the ESP32-CAM flash LED as the grow light.
  • Keep cables strain-relieved so the camera does not move when the chamber is opened.

Troubleshooting

ProblemLikely causeFix
Upload says failed to connect Board not in flash mode Connect GPIO0 to GND, press RST, upload again.
Serial Monitor shows unreadable text Wrong baud rate Set Serial Monitor to 115200.
Camera init failed Wrong board type, weak power, or non-AI-Thinker pinout Use AI Thinker ESP32-CAM, power from 5V, check module model.
Browser page does not load Wrong IP or Wi-Fi issue Check Serial Monitor for the latest IP. Make sure laptop and ESP32 are on the same network.
MQTT topics do not appear Wrong Pi IP or Mosquitto not running Run hostname -I on Pi, update MQTT_HOST, restart Mosquitto.
ESP32 keeps rebooting Power brownout Use a better 5V supply and shorter wires.

Definition Of Done For ESP32 Setup

  • germcam-1 opens in browser and shows an image.
  • germcam-2 opens in browser and shows an image.
  • The Pi receives germination/germcam-1/# MQTT topics.
  • The Pi receives germination/germcam-2/# MQTT topics.
  • Both cameras are physically fixed in repeatable positions.
